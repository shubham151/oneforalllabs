# One For All Labs

**Live URL:** [https://oneforalllabs.com](https://oneforalllabs.com)

## What is it?
This is the central portfolio and landing page for the One For All Labs ecosystem, a collection of clean, single-purpose developer and privacy tools.

## What does it do?
It serves as a fast, statically generated hub built with Next.js 15. It showcases active projects (like Text Sanitizer and Webhook Catcher), explains the mission of the lab, and provides direct links to the creator's GitHub and LinkedIn profiles.
